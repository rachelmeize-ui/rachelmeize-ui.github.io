# 个人网站 PRD（产品需求文档）

> 项目名称：张美泽个人网站
> 版本：v1.0
> 更新日期：2026-07-24

---

## 1. 项目目标

建立一个可长期更新的个人项目主页，展示我在金融科技领域的学习经历、技能储备和项目方向，为同学、教师和未来实习招聘者提供一个了解我的窗口。

## 2. 目标访问者与场景

| 访问者 | 访问场景 | 最先寻找的信息 |
|--------|---------|---------------|
| 同学 / 项目伙伴 | 课程合作前了解我的背景 | 专业方向、技能、做过的项目 |
| 教师 | 查看课程作业完成情况 | 网站结构、内容真实性、过程文档 |
| 实习招聘者 | 收到简历后了解更多信息 | 个人简介、技能、项目经历、联系方式 |

**一句话定位**：我是张美泽，深圳大学金融科技学院学生，正在探索 AI 与金融的交叉应用，希望用技术解决实际的金融问题。

## 3. 本期范围（必须包含）

### 3.1 五个基础区块

| 区块 | 内容 | 最低要求 |
|------|------|---------|
| Hero | 公开称呼、一句话定位、行动入口 | 首屏可见，按钮可点击 |
| About | 真实个人简介、专业与学习方向 | 无模板作者信息，无虚构经历 |
| Skills | 真实能力、工具或兴趣方向 | 内容具体，不堆砌空泛标签 |
| Projects | 至少 1 个项目卡片 | 本作业或标注"进行中"的金融科技项目 |
| Contact | 至少提供 GitHub 主页链接 | 链接有效可用 |

### 3.2 过程文档

- `docs/prd.md`（本文件）
- `docs/design.md`（设计说明）
- `docs/checklist.md`（验收清单）
- `report/final-report.md`（最终报告）
- `README.md`（项目说明 + Pages 链接）

### 3.3 截图证据

- `screenshots/homepage-desktop.png`（桌面端首页）
- `screenshots/homepage-mobile.png`（手机端首页）
- `screenshots/github-pages.png`（GitHub Pages 访问证明）
- `screenshots/checklist.png`（完成的 Checklist）

## 4. 本期明确不做

- 不做登录、注册系统
- 不做数据库或后端服务
- 不做支付功能
- 不做访客追踪 / 数据采集
- 不引入复杂框架（React/Vue 等），保持纯静态 HTML/CSS/JS
- 不做博客系统或内容管理后台

## 5. 成功标准

| 维度 | 标准 | 验证方式 |
|------|------|---------|
| 可访问性 | GitHub Pages 链接可在无痕窗口打开 | 实际访问验证 |
| 内容真实性 | 五个区块齐全，内容属于本人，无模板占位 | 人工检查 |
| 移动端可用 | 手机端文字可读，无横向溢出 | 手机截图 |
| 链接有效 | 导航、项目链接、GitHub 链接均可点击 | 逐个点击验证 |
| 过程完整 | PRD、Design、Checklist 与网站一致 | 对照检查 |
| 提交成功 | TA-Claw 预览→确认→Submitted successfully | 成功回执 |

## 6. 隐私边界（不可公开的信息）

- 不公开手机号码
- 不公开家庭住址（城市级别可以）
- 不公开身份证号
- 不公开课程邀请码、API Key、Token
- 不公开 .env 文件或任何密码
- 不公开不适合公开的私人照片
