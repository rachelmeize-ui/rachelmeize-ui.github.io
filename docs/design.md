# 个人网站 Design（设计说明）

> 项目名称：张美泽个人网站
> 版本：v1.0
> 更新日期：2026-07-24

---

## 1. 页面区块与浏览顺序

页面采用单页垂直滚动结构，访问者从上到下依次看到：

```
┌─────────────────────────────┐
│  Hero — 首屏印象              │  访问者第一眼看到：姓名 + 定位 + CTA
├─────────────────────────────┤
│  About — 关于我              │  一段话介绍我是谁、在学什么
├─────────────────────────────┤
│  Skills — 技能与兴趣          │  具体、不空泛的能力标签
├─────────────────────────────┤
│  Projects — 项目展示          │  至少 1 个项目卡片，含链接
├─────────────────────────────┤
│  Contact — 联系方式           │  GitHub 链接，可选邮箱
└─────────────────────────────┘
```

顶部固定导航栏包含五个锚点链接，点击可平滑滚动到对应区块。

## 2. 颜色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色（标题、强调） | 深蓝 | `#1a365d` |
| 辅色（按钮、链接 hover） | 青色 | `#319795` |
| 背景 | 白色 | `#ffffff` |
| 次背景（区块交替） | 浅灰 | `#f7fafc` |
| 正文文字 | 深灰 | `#2d3748` |
| 次要文字 | 中灰 | `#718096` |

**原则**：最多 2 个主色，整体风格干净专业，符合金融科技方向。

## 3. 字体层级

| 层级 | 用途 | 字号 | 字重 |
|------|------|------|------|
| H1 | Hero 区块姓名 | 2.5rem | 700 |
| H2 | 各区块标题 | 1.75rem | 600 |
| H3 | 项目名称 | 1.25rem | 500 |
| Body | 正文 | 1rem | 400 |
| Small | 标签、注释 | 0.875rem | 400 |

字体族：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`

## 4. 桌面端要求

- 最大内容宽度：960px，居中
- 导航栏固定在顶部，滚动时保持可见
- Hero 区块占满首屏高度（min-height: 100vh）
- 项目卡片：网格布局，每行 2 列
- 行间距和留白充足，不拥挤

## 5. 移动端要求（移动优先）

- 断点：768px 以下切换为移动端布局
- 导航栏折叠为汉堡菜单或简化为图标
- 项目卡片：单列排列
- Hero 字号适当缩小（clamp 响应式）
- 所有文字最小 14px，确保可读
- 触摸目标最小 44x44px
- 无横向溢出

## 7. 模板保留与修改说明

> 注：如果使用教师统一模板，以下内容需根据实际模板调整。

### 保留的部分
- 页面整体结构框架（单页滚动）
- 响应式布局基础
- 基础 CSS reset

### 修改的部分
- 所有文本内容替换为真实个人信息
- 颜色方案调整为深蓝 + 青色
- 字体层级重新设定
- 项目区块内容替换为真实项目
- Contact 区块替换为真实 GitHub 链接
- 移除模板作者的姓名、示例项目和占位文字

## 8. 图片与素材来源

| 素材 | 来源 | 许可状态 |
|------|------|---------|
| 头像 | 本人提供或使用占位符 | 本人授权 |
| 项目截图 | 本人项目实际截图 | 本人授权 |
| 图标 | 纯 CSS 实现或 SVG 内联 | 无需外部许可 |
| 字体 | 系统字体栈 | 无需外部许可 |

**原则**：不使用未经授权的图片；所有外部素材标注来源和许可。
